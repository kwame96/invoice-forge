# Invoice Forge

**Professional invoice generator for freelancers and consultants.**

Create, preview, and print beautiful invoices in seconds — no account, no subscription, no backend.

## Live Demo

👉 **[Try it free on GitHub Pages](https://kwame96.github.io/rock-paper-scissors/)**

## Features

- Live invoice preview as you type
- Customizable business & client info
- Line items with auto-calculated totals
- Tax rate support
- Multiple currencies (USD, EUR, GBP, CAD, AUD, JPY)
- Print to PDF via browser (no extra software needed)
- Data persists between sessions (localStorage)
- Zero dependencies — works offline

## Sell It

List on [Gumroad](https://gumroad.com) as a digital product ($12–15 one-time):

1. Create a free Gumroad account
2. New Product → Digital Product → name "Invoice Forge Pro"
3. Upload a zip of `index.html`
4. Set price and publish
5. Replace `YOUR_GUMROAD_URL` in `index.html` with your Gumroad link

## Deploy (GitHub Pages — free)

1. Repo Settings → Pages → Branch: `main` → Save
2. Your app is live at `https://<username>.github.io/<repo>/`
